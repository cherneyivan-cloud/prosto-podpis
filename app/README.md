# Просто подпись — GUI

Графический интерфейс на Rust + egui. Вызывает `cryptoline-cli.exe`
(движок из `../cli`) для подписи и проверки; закрытый ключ остаётся
в контейнере КриптоПро CSP.

## Сборка

Из корня репозитория:

```powershell
cd cli
cargo build --release

cd ..\app
cargo build --release
copy ..\cli\target\release\cryptoline.exe ..\app\target\release\cryptoline-cli.exe
```

Результат: `app\target\release\Podpis.exe` рядом с `cryptoline-cli.exe`.

## Возможности

- Очередь документов: Drag & Drop, поиск, сортировка, `Ctrl+A`.
- Режимы подписи: открепленная / присоединенная; отдельный файл на
  сертификат / одна общая подпись на несколько сертификатов.
- Сертификаты из хранилища Windows и из файлов `.der/.cer/.pem`.
- Проверка Base64 и бинарных DER/BER подписей.
- Отчёты TXT и XLSX в папке с документами, кнопка «Открыть папку».
- Тёмная тема, безрамочное окно, собственные кнопки окна.
- Предупреждение перед подписанием файлов больше 50 МБ.

## Настройки по умолчанию

- Открепленная подпись — включена.
- Каждая в отдельный файл — выключена (общая подпись на все сертификаты).
- Формат `.sig`, кодировка Base64.

## Структура

```
src/
├── main.rs    — окно, иконка, аргументы командной строки
├── app.rs     — экраны, виджеты, логика подписи
├── theme.rs   — палитра, шрифты, тени
├── icons.rs   — векторные иконки
├── report.rs  — отчёты TXT и XLSX
└── win.rs     — Win32: HWND, тёмный заголовок, ресайз
assets/        — иконка приложения
```
