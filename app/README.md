# Просто подпись — GUI для подписи документов

Десктопное приложение на Rust + egui для подписи, проверки и упаковки
документов по ГОСТ Р 34.10-2012 (Streebog-256). Подпись выполняется через
КриптоПро CSP: закрытый ключ не покидает контейнер.

```
target/release/
├── Podpis.exe           — GUI
└── Podpis-cli.exe       — CLI-движок подписи (лежит рядом с GUI)
```

## Возможности

- **Документы** — очередь файлов с иконками типов, статусами и поиском.
  Добавление кнопкой «+», перетаскиванием (Drag & Drop) или аргументами
  командной строки. Ctrl+клик — несколько файлов, Ctrl+A — выбрать все.
  У подписанных документов рядом со статусом показываются ФИО подписантов.
- **Подписание** — плавающая панель с двумя независимыми режимами:
  - **Открепленная подпись** — включена: отдельный файл `.sig`;
    выключена: содержимое документа вкладывается в файл подписи
    (присоединенная подпись, обычно `.p7s`).
  - **Каждая в отдельный файл** — включена: свой файл подписи на каждый
    сертификат; выключена: один общий файл CMS со всеми подписантами.
  Дополнительно: упаковка в ZIP, формат `.sig` / `.p7s`, Base64 / DER.
  Текущий режим подписан под тумблерами.
- **Сертификаты** — загрузка из `Cert:\CurrentUser\My` и импорт файлов
  `.der` / `.cer` / `.pem`; ФИО приводится к виду «Фамилия Имя Отчество».
- **Проверка ЭП** — массовая проверка: документы и подписи добавляются
  списками, пары подбираются по имени (порог совпадения 80%).
  Понимает Base64 и DER/BER. Строгий лимит: документ и файл подписи не
  больше 80 МБ. После успешной проверки подпись переименовывается в
  `<имя документа>_<Фамилия_ИО>.sig`.
- **Архив ZIP** — сбор всех подписей в один архив.
- **Отчёт о подписях** — после подписания в папке с документами появляются
  `Отчёт о подписях.txt` и `Отчёт о подписях.xlsx`: документ, размер,
  статус, подписант, файл подписи, hash подписи (SHA-256) и дата.
- **Открыть папку** — кнопка рядом со статусом после подписания открывает
  папку с подписанными документами в Проводнике.
- **Обновления** — кнопка «Проверить обновления» в настройках сверяет
  версию с публичным манифестом.
- **Инструкция** — PDF со скриншотами и обозначениями, открывается из
  настроек (файл лежит рядом с `Podpis.exe`).
- Иконка приложения встроена в `Podpis.exe` (видна в Проводнике и на
  панели задач).
- **Инспектор** — метаданные документа, hash-сумма Streebog-256,
  подписанты с подсказками и связанные файлы.

## Дизайн

Тёмная матовая тема Dark Slate UI:

| Роль | Цвет |
| --- | --- |
| Фон окна и сайдбара | `#232530` |
| Рабочая область | `#2B2D3A` |
| Карточки и панели | `#353849` |
| Акцент | `#4B6BFB` |
| Основной текст | `#FFFFFF` |
| Метаданные | `#8E92A4` |

Типографика — Roboto (или Segoe UI), заголовки полужирные. Иконки
векторные, рисуются примитивами egui (`src/icons.rs`). Тени мягкие,
скругления 12–16 px.

Окно без системного заголовка: верхняя панель и логотип в сайдбаре
совмещены с зоной перетаскивания, справа — собственные кнопки
свернуть / развернуть / закрыть. Ресайз — за невидимые полосы по краям.
Иконка приложения (`assets/app_icon.png`, RGBA — `assets/app_icon_256.rgba`)
показывается в сайдбаре и в панели задач.

Макет: сайдбар с навигацией, центральная колонка с очередью документов,
правый инспектор и плавающая панель подписания поверх него.

## Подпись

1. Выберите документы (клик; Ctrl+клик — несколько).
2. Загрузите сертификаты в разделе «Сертификаты» или через панель.
3. Отметьте сертификаты и нажмите круглую кнопку с пером.

GUI вызывает `Podpis-cli.exe sign --file <док> --cert <сертификат>`,
затем при необходимости переименовывает результат в `.p7s`, конвертирует
Base64 → DER и упаковывает подписи в ZIP. Имя файла подписи формирует CLI:
`<имя>_<Фамилия_ИО>.sig`, например `Документы_Черней_ИВ.sig` (фамилия
полностью, имя и отчество — первыми буквами).

## Проверка

- Массовый режим: документы и подписи лежат в двух списках, пары
  подбираются автоматически по имени. Порог совпадения — **80%**,
  поэтому `1695(1).20-ТКР4.9.3 изм.2.pdf.sig` находится к
  `1695.20-ТКР4.9.3 изм.2.pdf` (94%).
- Перетаскивание: `.sig` / `.p7s` уходят в раздел подписей, документы —
  в раздел документов; при наличии подписей окно сразу открывает
  «Проверку ЭП».
- Кнопка «Проверить все» проверяет все сопоставленные пары и показывает
  результат по каждой.
- Строгий лимит: документ и файл подписи — не больше 80 МБ, иначе
  проверка не выполняется.
- После успешной проверки подпись автоматически переименовывается по
  тому же образцу:
  `1695.20-ТКР4.9.3 изм.2.pdf.sig` → `1695.20-ТКР4.9.3 изм.2_Дубинец_ДВ.sig`.
  Если такое имя уже занято, добавляется суффикс `_2`, `_3` и т.д.

## Обновления и инструкция

- «Настройки» → «Проверить обновления»: запрашивает публичный манифест
  `prosto-podpis-updates` и сравнивает версии. Если доступна новая —
  появляется кнопка «Открыть страницу».
- «Настройки» → «Открыть инструкцию»: PDF со скриншотами и подсказками.
  Файл `Просто подпись — инструкция.pdf` лежит рядом с `Podpis.exe`.

## Требования

- Windows 10/11 x64
- КриптоПро CSP с контейнером закрытого ключа
- Сертификат с открытым ключом ГОСТ Р 34.10-2012 (хранилище Windows или файл)
